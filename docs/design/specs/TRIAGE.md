# TRIAGE — Subsystem Behaviour Specifications

TRIAGE-01  Triage converts a raw inbox item into a mature typed node, allocates a sequential ID, and stamps explicit author attribution.
TRIAGE-02  Triage supports establishing directed candidate edges to existing nodes during promotion.
TRIAGE-03  Discarding an inbox item deletes it permanently without creating a node.
TRIAGE-04  The web triage surface guides rapid keyboard processing and presents an empty state on Inbox Zero.

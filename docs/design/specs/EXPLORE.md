# EXPLORE — Subsystem Behaviour Specifications

EXPLORE-01  Full-text search locates nodes across body text, titles, tags, and IDs.
EXPLORE-02  Multi-facet filtering filters the corpus by domain, node type, tag, state, and minimum CML level.
EXPLORE-03  The web Explore landing page applies search queries and facet filters dynamically.
EXPLORE-04  The Node detail view renders frontmatter attributes, CML level breakdown, and bidirectional edge links.

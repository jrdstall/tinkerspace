# INTAKE — Subsystem Behaviour Specifications

INTAKE-01  Files dropped into `iw-vault/drop/` (e.g. tablet sketches, PDFs) are discovered on request without background watchers.
INTAKE-02  Intake creates stub artifact/source nodes with dropped files attached and markdown embed links populated.
INTAKE-03  Intake attaches dropped files to existing mature nodes by appending reference links to node body text.
INTAKE-04  The web intake interface lists dropped assets and provides workflows for stub creation and node attachment.

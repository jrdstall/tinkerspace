# CAPTURE — Subsystem Behaviour Specifications

CAPTURE-01  A raw thought is captured with zero upfront classification or taxonomy prompts.
CAPTURE-02  Inbox discovery scans both standalone markdown files and line-based entries in `quick.txt`.
CAPTURE-03  Web quick capture endpoint accepts text and updates the pending inbox count badge.
CAPTURE-04  Deleting an inbox item removes its underlying file or entry from storage.

# E2E — Subsystem Behaviour Specifications

E2E-01  Raw capture to triage into a typed Idea note with initial CML derivation.
E2E-02  Multi-step workflow creation with dependency graph and on-demand ready-set computation.
E2E-03  Work unit dispatch via CLI/MCP and deliverable submission with proper attribution.
E2E-04  Result collection parsing scores/verdicts, registering artifacts via Open Hospitality, and updating subject note CML.
E2E-05  Unblocking downstream workflows and ingesting external notes from foreign vaults.
